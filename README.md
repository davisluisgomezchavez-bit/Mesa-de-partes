
# Mesa de Partes Digital-Salud

## Descripción
Prototipo académico desarrollado en Python para registrar y organizar solicitudes sanitarias durante emergencias por desastres naturales.

## Funcionalidades
- Registrar solicitudes sanitarias.
- Validar los datos ingresados.
- Clasificar solicitudes por prioridad.
- Buscar solicitudes mediante un código.
- Ordenar y consultar los registros.
- Guardar información en un archivo de texto.

## Requisitos
- Python 3.

## Ejecución
Abrir una terminal dentro de la carpeta del proyecto y ejecutar:

python mesa_partes_digital_salud.py

## Consideraciones
Este prototipo tiene fines educativos. La clasificación de prioridad es administrativa y no reemplaza la evaluación del personal sanitario.
